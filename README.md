## Overview
This project is an interactive Excel dashboard designed to analyze global salary trends for data professionals, including Data Analysts, Data Scientists, Data Engineers, and Machine Learning Engineers. 

## Dataset & Features
The dataset encompasses thousands of job postings across various platforms (LinkedIn, Indeed, ZipRecruiter) and tracks key variables:
* **Job Titles:** Data Scientist, Data Analyst, Data Engineer, etc.
* **Salary Data:** Yearly averages, hourly averages, and median salaries.
* **Geographical Trends:** Salary comparisons across different countries.
* **Job Types:** Full-time, Part-time, Contract, and Internship comparisons.
* **Required Skills:** Tracking highly requested tools like Python, SQL, Tableau, and AWS.

## Tools Used
* **Microsoft Excel:** Data cleaning, data validation, and aggregation.
* **Pivot Tables & Charts:** For extracting dynamic summaries from raw job posting data.
* **Interactive Dashboard:** Slicers and KPIs built to quickly filter salaries by Job Title, Country, and Work Type.
